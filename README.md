## 👋 About Me

- 🏫 OSU Undergraduate CSE 2022-2026, USC Master CS 2026-Current
- 🔬 Currently exploring LLMs and AI agents
- 🌱 Interested in agent routing, retrieval (RAG) and LLM evaluation
- 💻 Background in backend development with Python and Java


## 🔭 Focus

- **Intent recognition and routing**: combining model, embedding and keyword signals, with safe behavior when the model call fails
- **LLM evaluation**: labelled datasets, dev/test splits, confidence intervals and paired significance tests
- **Retrieval**: natural-language search over Elasticsearch and vector stores, with answers grounded in the results
- **Backend services**: REST APIs in FastAPI, Flask and Rails, with caching, role-based access control and SQL
